# BreadlandPlugin

Модульный Paper-плагин для сервера Breadland. Сейчас в нём два модуля:

- **Death Note** — тетрадь смерти с записями по времени, принципом «знать в лицо» и глазами шинигами.
- **GodVanish** — режим бога смерти: игрок невидим для всех, кроме одного привязанного игрока (и операторов).

## Требования

- Paper **1.21.8** или **1.21.11** — один и тот же jar работает на обеих версиях
- Java **21**

Других плагинов-зависимостей нет. Версии ниже 1.21.7 не подойдут: в них нет Dialog API, через который работает окно записи.

## Сборка

```bash
./gradlew build
```

Готовый jar: `build/libs/`.

## Совместимость с версиями

Поддерживаемые версии перечислены в `build.gradle`:

```groovy
ext.supportedPaperVersions = ['1.21.8', '1.21.11']
```

Плагин компилируется против самой старой из них, а `./gradlew build` (точнее, `check`) проверяет его против каждой:

- `compileAgainst<версия>` — исходники собираются с API этой версии;
- `checkBinary<версия>` — каждый класс, метод и поле Bukkit/Paper/Adventure, которые использует готовый jar, существуют в этой версии. Если чего-то нет, сборка падает со списком того, чего не хватает.

Отдельно проверить все версии: `./gradlew checkCompat`. Чтобы поддержать новую версию, добавьте её в список и запустите сборку.

Запустить чистый сервер нужной версии через Gradle (в папке `run/`):

```bash
./gradlew runServer -PmcVersion=1.21.11
```

## Локальный тестовый сервер

В папке `server/` лежит Paper для тестов. Она в `.gitignore`: миры, логи и конфиги сервера в репозиторий не попадают.

1. Положите jar Paper в `server/` (сейчас `paper-1.21.8-60.jar`) и создайте `server/start.bat`:
   ```bat
   @echo off
   cd /d "%~dp0"
   java -Xms1G -Xmx2G -jar paper-1.21.8-60.jar --nogui
   pause
   ```
2. Соберите плагин и скопируйте его на сервер:
   ```bash
   ./gradlew deployToServer
   ```
   Плагин окажется в `server/plugins/BreadlandPlugin.jar`.
3. Запустите `server/start.bat`. При первом запуске сервер остановится и попросит принять EULA: поставьте `eula=true` в `server/eula.txt` и запустите снова.
4. Подключитесь к `localhost`.

После изменений в коде: остановите сервер (`stop`), выполните `./gradlew deployToServer` и запустите его снова.

## Death Note

### Как это работает

- Админ выдаёт тетрадь: `/deathnote give <ник>`. Вместе с ней игрок получает книгу правил.
- ПКМ по тетради открывает её. Содержимое рисует сервер: обложка, записи с обратным отсчётом, зачёркнутые имена погибших. При наведении на имя видны подробности.
- Кнопка «✎ Вписать имя» открывает окно ввода: имя и через сколько наступит смерть (необязательно: `40с`, `5м`, `1ч 30м`). Смерть всегда от сердечного приступа.
- Записи хранятся на сервере (`plugins/BreadlandPlugin/deathnote-data.yml`). Стереть или исправить их нельзя. Отсчёт переживает рестарт, а выход с сервера не спасает: жертва умрёт при входе.
- Писать может только владелец, и тетрадь должна быть у него с собой. Со смертью владельца тетрадь исчезает, но уже вписанные смерти исполнятся.
- Если вписать своего бога смерти (игрока, который привязан к вам через `/godvanish`), владелец умрёт, а тетрадь исчезнет.
- Защита: тетрадь нельзя скопировать на верстаке или в автокрафтере, положить на кафедру. Выброшенная тетрадь не горит и не исчезает, а упавшая в пустоту возвращается к владельцу.

### Тестовая кукла

`/dn dummy [имя]` ставит перед вами стойку для брони с подписью `[Кукла] <имя>` (по умолчанию `Dummy1`, `Dummy2`…). Её имя можно вписать в тетрадь как ник игрока: работают «знать в лицо» (кукла смотрит на вас), отсчёт, подпись глаз шинигами и сообщение о смерти, а по истечении времени кукла рассыпается. Куклы не сохраняются: после рестарта сервера они исчезают, а записи на них утрачивают силу.

### Знать в лицо

Режим задаётся в `events.yml` → `death-note.know-face.mode`:

| Режим | Условие |
|---|---|
| `none` | можно вписать кого угодно |
| `radius` | жертва в сети, в том же мире и не дальше `radius` блоков |
| `seen` | владелец видел жертву (в поле зрения, не за стеной) за последние `memory-minutes` |
| `face` | как `seen`, но жертва смотрела на владельца и не прятала лицо (тыква, голова моба, невидимость) |

### Глаза шинигами

- Админ предлагает сделку: `/deathnote eyes <ник>` (только владельцу тетради). Игрок соглашается или отказывается в окне.
- Пока игрок владеет тетрадью, у него вдвое меньше сердец. В обмен он видит над головами игроков их настоящие ники, а у вписанных в тетрадь ещё и обратный отсчёт.
- При потере тетради глаза пропадают, а сердца возвращаются.

### Команды

Команда `/deathnote`, сокращение `/dn`.

| Команда | Право | Что делает |
|---|---|---|
| `/dn give <ник>` (или `/dn <ник>`) | `breadland.deathnote.create` | выдать тетрадь |
| `/dn revoke <ник>` | `breadland.deathnote.admin` | уничтожить тетрадь игрока |
| `/dn eyes <ник>` | `breadland.deathnote.admin` | предложить сделку на глаза |
| `/dn eyes revoke <ник>` | `breadland.deathnote.admin` | забрать глаза |
| `/dn list` | `breadland.deathnote.admin` | активные записи |
| `/dn dummy [имя]` | `breadland.deathnote.admin` | поставить тестовую куклу перед собой |
| `/dn dummy remove <имя>` / `list` / `clear` | `breadland.deathnote.admin` | убрать куклу, список кукол, убрать все |
| `/dn reload` | `breadland.deathnote.admin` | перезагрузить `events.yml` |

`breadland.deathnote.identify` — игрок с этим правом видит название «Тетрадь смерти» вместо «Книга».

Все права по умолчанию есть у операторов.

### Настройки

Всё в `plugins/BreadlandPlugin/events.yml`:

- `death-delay`, `min-delay`, `max-delay`, `cooldown` — время по умолчанию, границы и перезарядка (в секундах);
- `know-face` — режим «знать в лицо»;
- `causes.heart-attack.death-message` — сообщение о смерти от тетради;
- `messages` — все сообщения (цвета через `&`).

Новые ключи из обновлений плагина дописываются в файл автоматически, уже изменённые значения не трогаются.

## GodVanish

`/godvanish <ник>` (право `breadland.godvanish`) — включает или выключает невидимость. Вас видит только указанный игрок и операторы, и вы становитесь его богом смерти. Если этот игрок выходит с сервера, режим выключается.

## Структура

```
src/main/java/me/tedecti/
├── BreadlandPlugin.java         — точка входа
├── config/ConfigManager.java    — загрузка конфигов
├── commands/                    — /godvanish
├── managers/GodVanishManager    — GodVanish
└── events/deathnote/
    ├── DeathNoteManager         — ядро: выдача, запись, отсчёт, владение
    ├── DeathNoteHandler         — события (открытие, защита от копирования и т.п.)
    ├── DeathNoteCommand         — /deathnote
    ├── DeathNoteBook            — вид тетради и окна ввода
    ├── DeathNoteStorage         — хранение данных на диске
    ├── DeathCauses              — смерть от тетради (сообщение, эффект)
    ├── FaceMemory               — «знать в лицо»
    ├── ShinigamiEyes            — глаза шинигами
    └── TimeFormat, DeathEntry, NoteRecord
```
